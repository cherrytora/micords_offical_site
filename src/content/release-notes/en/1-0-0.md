## 🎉 Micords Is Live!

Thank you to everyone who waited. Micords is now officially available.

### Core Features

* **Cat Profile** — Add photos, breed, birthday, and basic health info
* **Daily Log** — Track food, water, bathroom habits, and weight
* **Health Trend Charts** — Blood test values automatically plotted as visual graphs
* **Smart Reminders** — Vaccine, deworming, follow-up, and medication reminders with push notifications
* **Medical Records** — Vet visit records and blood test logs
